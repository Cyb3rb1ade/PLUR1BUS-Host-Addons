## What's new

- One-line installers for OpenClaw hosts: `install-plugin.sh` (Linux, macOS, WSL) and `install-plugin.ps1` (Windows, beta). They verify a signed feed, snapshot the store, install through `openclaw plugins`, and roll back on a failed check. Also `--update`, `--rollback`, `--uninstall`.
- Hermes host mode: `--host hermes` (`-Host hermes` in the `.ps1`) installs the memory provider into a Hermes agent (0.21.4 or newer) with a local sidecar (binary pinned by SHA-256 in the feed). No Node: pinned portable Node 24.21.0.
- Build attestations for the installer bundle and both bootstraps.

## Fixes

- A fresh state directory without `openclaw.json` is no longer an invalid config.

## Upgrade notes

- No store migration; existing installs keep configuration and embedding choice.
- An install from `install-memory-system.sh` needs `--adopt-legacy`; disable the `protect-plur1bus-deploy.sh` cron line first.
- Details: `docs/distribution.md`.
